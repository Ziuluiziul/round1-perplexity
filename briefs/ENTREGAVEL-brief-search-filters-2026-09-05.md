# Brief — Search API: filtros, multi-query e budget · set/2026

**Pacote:** R$ 20 · docs-only  
**Fonte:** https://docs.perplexity.ai/docs/search/quickstart.md · Pricing

## Resumo
1. Search = resultados crus; Agent = resposta com citações.  
2. `max_results` 1–20 (default 10).  
3. Multi-query: até **5** queries / POST = **1** billing unit; rate-limit conta **cada** query.  
4. `search_domain_filter`: allowlist **ou** denylist (`-domain`), máx. 20; não misturar.  
5. `search_language_filter`: ISO 639-1, máx. 10.  
6. `country`: ISO 3166-1 alpha-2.  
7. Budget: `search_context_size` low/medium/high **ou** `max_tokens`/`max_tokens_per_page` (não combinar com context_size).
